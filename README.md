# CS Lab Assignment Submission Tracker
A web-based dashboard designed for Computer Science students to organize and track their academic lab activities in one place. The system helps students keep track of upcoming lab tasks, pending assignments, viva dates, and grading deadlines.

# Overview
Managing multiple lab assignments, submission dates, viva schedules, and grading deadlines can be difficult for students. **CS Lab Assignment Submission Tracker** provides a centralized dashboard where students can easily monitor their academic tasks and stay organized.

# Features
* View upcoming CS lab tasks
* Track pending assignments
* Monitor assignment submission deadlines
* Keep track of viva dates
* Organize grading deadlines
* Mark assignments and tasks as completed
* View important academic dates
* Easily identify pending and upcoming tasks
* Simple and user-friendly dashboard

# Dashboard
The dashboard provides students with an overview of their academic workload, including:
* Upcoming Lab Tasks
* Pending Assignments
* Upcoming Viva Dates
* Submission Deadlines
* Completed Tasks
